# E-Commerce Shopping Cart — PPT + Original Code

Run backend: `cd backend` then `mvn spring-boot:run`
Run frontend: `cd frontend` then `python -m http.server 5500`
Open: http://localhost:5500

This version follows the supplied PPT workflow and the supplied Java code:
Product Catalog -> Select Product -> Validate ID -> Add to Cart -> View/Update/Remove -> Calculate Total -> Confirm Order.

Java classes: Product, CartItem, ProductCatalog, ShoppingCart, CartController.
Collections: HashMap and ArrayList.
